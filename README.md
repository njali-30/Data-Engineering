# Airbnb Data Cleaning and Exploratory Data Analysis

## Project Overview

This project focuses on cleaning, validating, transforming, and exploring the **New York City Airbnb Open Data** dataset using Python.

The objective is to build practical experience with data-quality assessment, data preparation, feature engineering, and exploratory data analysis.

## Tech Stack

* Python

* Pandas

* NumPy

* Matplotlib

* Seaborn

* Jupyter Notebook

## Dataset

**Dataset:** New York City Airbnb Open Data

**Source:** [NYC Airbnb Open Data — Kaggle](https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data)

The raw dataset is kept outside the project folder. Update the dataset path in the notebook before running it.

## Workflow

The notebook follows this sequence:

1. Load and understand the dataset.

2. Assess data quality.

3. Clean invalid and inconsistent records.

4. Validate the cleaned data.

5. Create useful derived features.

6. Perform exploratory data analysis.

7. Export the cleaned dataset as a CSV file.

The detailed implementation and outputs are available in the notebook.

## How to Run

### 1. Install the required libraries

```
pip install pandas numpy matplotlib seaborn jupyter ipykernel
```

### 2. Configure the dataset path

Update the `file_path` variable in the notebook to match the location of your local `AB_NYC_2019.csv` file.

### 3. Run the notebook

Open `airbnb_complete_analysis.ipynb` in VS Code or Jupyter Notebook and execute the cells in order.

### 4. Check the output

After successful execution, the notebook generates:

```
cleaned_dataset.csv
```
